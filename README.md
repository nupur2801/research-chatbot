📘 Research Chatbot

A simple research chatbot built using Python and Groq API that answers questions and summarizes information using AI.

🚀 Features

Ask research-based questions

Get quick AI-generated answers

Summarizes complex topics

🛠️ Tech Stack

Python

Groq API

Jupyter Notebook / Google Colab

⚙️ Setup
pip install groq python-dotenv

Add your API key:

import os
os.environ["GROQ_API_KEY"] = "your_api_key"
▶️ Run

Open research_chatbot.ipynb in Jupyter/Colab and run all cells.

💡 Example

Input: What is AI?
Output: AI is the simulation of human intelligence in machines.
